# ☕ Spinning Sip

Spinning Sip is a modern and responsive coffee café website designed using HTML and CSS.  
The website provides an elegant coffee shop experience with stylish sections, handcrafted curation, customer testimonials, menu navigation, and a clean user interface.

---

## 🚀 Features

- Responsive coffee café website
- Beautiful hero section
- Handcrafted coffee and food categories
- Customer testimonials section
- Interactive navigation bar
- Login page integration
- Footer with contact details and social media links
- Google Maps location embed
- Smooth "Back to Top" button

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome Icons
- Google Fonts
